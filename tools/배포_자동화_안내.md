# 서버 배포 자동화 안내

> 결론: **평소엔 `git push` 만 하면 서버까지 자동 배포**되게 만들 수 있습니다(방법 B, 1회 설정).
> 설정 전이거나 급할 땐 **`배포하기.bat` 더블클릭**(방법 A)으로 배포합니다.

| | 방법 A — `배포하기.bat` | 방법 B — GitHub 자동 배포 |
|---|---|---|
| 언제 | 지금 바로 / 사내 서버 스크립트까지 갱신할 때 | 설정 후 매번 자동 |
| 하는 일 | 테스트 → 로그인 확인 → Worker 배포 → 응답 확인 → (선택) 사내 서버 갱신 | `cloudflare-worker.js`·`wrangler.toml` 이 바뀐 push 마다 Worker 배포 |
| 필요한 것 | 이 PC에 Node.js | GitHub 저장소에 비밀값 2개 등록 (1회) |

---

## 방법 A — `배포하기.bat` 더블클릭

1. 프로젝트 폴더에서 **`배포하기.bat`** 더블클릭
2. 테스트가 자동으로 돕니다. 하나라도 실패하면 **배포하지 않고 멈춥니다** (운영 사고 방지)
3. Cloudflare 로그인이 만료됐으면 **브라우저가 열립니다** → 로그인 → **[Allow]** 클릭
4. Worker 배포 후 서버가 정상 응답하는지 자동 확인
5. 마지막에 "사내 서버도 갱신할까요? (Y/N)"
   - `sync/crm-deploy-tickets-sync.js` 를 고쳤을 때만 **Y** → 파트너센터 서버 비밀번호를 **본인이 직접 입력**
   - 그 외엔 **N**

> PowerShell 에서 직접 실행하려면:  `node tools/deploy.mjs`
> (Windows PowerShell 5.1 은 `&&` 를 지원하지 않습니다. 명령은 한 줄씩 실행하세요.)

---

## 방법 B — GitHub 자동 배포 켜기 (1회, 약 5분)

### 1단계. Cloudflare 에서 배포용 토큰 만들기
1. https://dash.cloudflare.com/profile/api-tokens 접속 → **Create Token**
2. **Edit Cloudflare Workers** 템플릿 → **Use template**
3. Account Resources: **Include → (우리 계정)** / Zone Resources: **All zones** (기본값 그대로)
4. **Continue to summary → Create Token** → 표시된 토큰을 **복사** (이 화면을 닫으면 다시 볼 수 없음)

### 2단계. GitHub 저장소에 비밀값 등록
1. https://github.com/emitlight/deploy-schedule/settings/secrets/actions 접속
2. **New repository secret** 을 두 번 눌러 아래 2개 등록

| Name | Secret |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 1단계에서 복사한 토큰 |
| `CLOUDFLARE_ACCOUNT_ID` | `432a7fd8cfc5ec28c1ea7fdf035c47f3` |

### 3단계. 확인
1. https://github.com/emitlight/deploy-schedule/actions/workflows/deploy-worker.yml 접속
2. **Run workflow → Run workflow** → 1~2분 뒤 초록 체크(✅) 확인

이후로는 `cloudflare-worker.js` 가 바뀐 push 마다 자동 배포됩니다.

> 보안 검토 필요
> - 토큰은 **GitHub Secrets 에만** 넣고 채팅·메일·문서·코드에 붙여 넣지 마세요. 저장소가 **public** 입니다.
> - 토큰 권한은 "Workers 편집"으로 한정됩니다. 유출이 의심되면 1단계 화면에서 **Roll / Delete**.
> - 사내 서버 스크립트(방법 A 5단계)는 서버 비밀번호가 필요해 자동화 대상에서 일부러 뺐습니다.

---

## 비즈니스 효과
- **배포 실수 차단**: 테스트를 통과해야만 배포 → 깨진 규칙이 전 직원 화면에 나가는 일 방지
- **환경변수 삭제 사고 차단**: `--keep-vars` 를 사람이 매번 입력하지 않아도 됨
- **담당자 부재 시에도 배포 가능**: 방법 B 설정 후엔 push 권한만 있으면 누구나
